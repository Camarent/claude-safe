Course: dojo-kit/workspace/fr-numbers (private course, own git repo). Read CONTRACT.md sec 3/4/12 and /workspace/.notes/progress-migration.md first.
Goal: ordinals (-ième, première, seconde) become their own form/section. Lottery clips like "Notez bien le troisième numéro, il va s'afficher sur votre écran, le 28." are split in 2 recordings: "Notez bien le troisième numéro" (new ordinal form) and "il va s'afficher sur votre écran, le 28" (stays on number 28). About 55 of 892 clips contain an ordinal; split only lottery-style or clean standalone-phrase ones, skip incidental ones ("seconde période", "quatre premiers").
Decisions (owner): GPU is held by Strata (0.9 GB free), so all ASR runs on CPU: FRNUM_DEVICE=cpu, faster-whisper small, audio decoded via tools/harvest/asr_cut.decode_audio (ffmpeg; passing a file path fails on the av version). Measured 0.3 s per clip, word timestamps fine. Clips: .cache/clips/<id>.mp3; texts: audio/manifest.json clips.<id>.text.
Constraints: clip ids deterministic sha1(url#start_ms); clips.lock and ids.lock append-only, retired ids stay. Any id or save change needs a tested progress migration. Course tests live in the course tests/ dir (node --test from dojo-kit root, DOJO_KIT_ROOT; no skips). Existing form mechanism: tools/harvest/forms.py (register rules, PRIORITY), tools/levels.json, tools/gen-forms.js, tools/harvest/form_cut.py.
Out of scope: publishing, pushing, audio quality changes, other forms.
Settle in the plan: ordinal rule in forms.py vs a separate path; unit and level in levels.json; answer key (e.g. "3e"); ids for split clips (start_ms differs, so new ids) and retirement of the old combined clip without breaking progress; bulk ASR split as an ops phase.

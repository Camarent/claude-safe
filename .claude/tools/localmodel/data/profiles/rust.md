Rust principles (this project's norms):
- Function over 50 lines or more than 4 parameters: split or group the parameters; over 100 lines or 7 parameters is a must-split. Nesting depth 3 at most. A file over 400 lines gets split, not extended.
- Data from outside (import, save, JSON from JS): no `unwrap`, `expect`, indexing or unchecked division. Use `.get(i)`, `checked_*`, and return `Result`. Panics are bugs.
- At the WASM boundary: return `Result<T, JsError>`; one call per user action, not per item; avoid `format!`/`to_string` where a static string works.
- No more than one bool parameter; use an enum. Keep public paths stable when moving code (re-export).
- `cargo clippy -- -D warnings` must stay clean for what you touched. Regenerated files (schema, wasm) are regenerated by their script, never hand-edited.

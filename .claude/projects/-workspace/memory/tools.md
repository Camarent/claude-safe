description: Picking tools: web search before the browser, browser for 403 or interactive UI
metadata:
  type: feedback
---

- Use WebSearch/WebFetch first for anything a page states in text (opening hours, prices, policies). Use the browser only when the answer exists only in an interactive UI (driving times, "near me" lists, rating histograms).
- If WebFetch returns 403 or is blocked on a page that holds the answer, open it in the browser at once instead of settling for secondary sources.

**Why:** driving everything through the browser was slow, and logged-out pages hide data that a plain search returns.
**How to apply:** try search first, escalate to the browser on a block; see [[communication]] for reporting.
